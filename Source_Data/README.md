# Source data archive

This directory contains reviewer-facing, non-restricted derived tables used by the submitted Nature Cities package.
All file references in the manuscript and Supplementary Information use relative paths from the package root.

Key files:
- component_year_panel_full.csv: component-year panel with support fields, need proxies, residuals, retained-screen flags and denominator flags.
- diagnostic_ledger.csv: competing-explanation diagnostic ledger.
- public_support_score_fields.csv: public-support score field dictionary.
- need_composite_weights.csv: need-composite fields and weights.
- event_validation_design.csv: event-validation source-field map.
- source_table_existence_audit.csv: audit mapping all CSV file names mentioned in manuscript/SI to files in this archive.
- reference_doi_format_audit.csv: reference DOI syntax and format audit.

Raw third-party records are not redistributed as a single archive because they remain subject to source-specific licensing and access terms.
